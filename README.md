# Поварня

Локальное Linux-приложение для создания, поиска и визуального составления модульных кухонных рецептов.

Текущая версия: **0.6.17**.

## Что уже есть

- Flutter-проект для Linux с адаптивной компоновкой, рассчитанной на последующий перенос на телефон.
- Модель карточек и неограниченно вложенного дерева рецепта.
- Текстовый рендер шага: дерево показывается только при редактировании, в просмотре шаг выглядит одной строкой.
- Стабильный ключ иллюстрации `действие:минимальный-id-дочерней-карточки`.
- Локальная схема SQLite для карточек, рецептов, шаблонов, связей дерева и медиа-привязок.
- Браузерная документация с локальным поиском.

## Запуск и проверка

Для работы нужен Flutter stable. После клонирования установите зависимости и запустите проверки:

```bash
flutter pub get
flutter test
```

Запуск Linux-приложения:

```bash
flutter run -d linux
```

Сборка Linux release:

```bash
flutter build linux --release
```

Готовый бинарный файл появится в `build/linux/x64/release/bundle/povarnya`.

Сборка Android release:

```bash
flutter build apk --release
```

Для GitHub Release переименуйте готовый APK в `povarnya-android.apk`. Тег релиза должен совпадать с версией из `pubspec.yaml`, например `v0.6.17+1`.
