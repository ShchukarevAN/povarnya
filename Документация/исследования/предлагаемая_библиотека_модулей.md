# Выделенная библиотека модулей по корпусу 100 рецептов

Критерий включения: модуль встречается минимум в нескольких блюдах корпуса либо является базовым для отдельного повторяемого технологического приёма. Уникальные названия блюд, формы и редкие уточнения остаются в модуле «Текст».

## Новые ингредиенты

| Подгруппа | Модули для добавления |
|---|---|
| Овощи | Свёкла, Репа, Редька, Болгарский перец, Баклажан, Зелёный горошек, Сельдерей, Хрен |
| Грибы и лесные продукты | Грибы, Сушёные грибы, Клюква |
| Крупы и бобовые | Рис, Пшено, Овсяные хлопья, Манная крупа, Полба, Горох |
| Мясо и рыба | Говядина, Фарш, Рыба, Сельдь, Печень, Субпродукты, Фрикадельки |
| Молочное и яйца | Кефир, Сыр плавленый |
| Тесто и хлеб | Тесто, Ржаная мука, Панировочные сухари, Лапша |
| Консервация и жидкости | Квас, Рассол, Уксус, Томатный соус, Бульон |
| Приправы | Горчица, Хрен, Кориандр, Тмин, Гвоздика, Корица, Мёд, Ваниль |
| Фрукты и ягоды | Ягоды, Сухофрукты, Лимон, Чернослив |

## Новые действия

| Подгруппа | Модули для добавления |
|---|---|
| Подготовка | Очистить, Замочить, Разморозить, Просеять, Обсушить |
| Нарезка и измельчение | Нашинковать, Нарубить, Пропустить через мясорубку, Взбить |
| Тепловая обработка | Запечь, Приготовить на пару, Томить, Бланшировать, Пассеровать, Припустить |
| Тесто и формы | Раскатать, Слепить, Начинить, Панировать, Сформировать котлеты |
| Жидкости и заготовки | Залить, Процедить, Отжать, Заквасить, Замариновать, Засолить, Мочить, Стерилизовать |
| Завершение | Охладить, Украсить, Подать |

## Новые количественные и технологические модули

| Группа | Модули |
|---|---|
| Количества | Чайная ложка, Столовая ложка, Стакан |
| Температурные режимы | Слабый огонь, Средний огонь, Сильный огонь |
| Состояния | До мягкости, До золотистой корочки, До кипения, До однородности |

Для последних четырёх состояний на первом этапе предпочтительнее «Текст»: они не имеют единой числовой проверки. Отдельными модулями их следует делать только после появления нескольких рецептов с одинаковой структурой.

## Реализованные дополнения: ноябрь 2026

В рабочем каталоге уже добавлены отдельные карточки **Кости**, **Редис**
(не путать с ранее добавленной **Редькой**) и **Зелёный лук**, а также
действия **Обвалять** и **Защипнуть**. Карточка «Сливочное масло» допускает
только дочерний модуль «Масса» в граммах: «Объём» в миллилитрах не
предлагается как допустимое вложение и не может быть перенесён в неё.

## Шаблоны для последующего добавления

| Шаблон | Состав |
|---|---|
| Пассеровать овощи | Пассеровать → Лук/Морковь → Масло → Время |
| Приготовить зажарку | Жарить → Лук, Морковь → Масло → Время |
| Сварить крупу | Варить → Крупа, Вода/Молоко, Соль → Время |
| Замесить тесто | Смешать → Мука, Жидкость, Дрожжи/Разрыхлитель, Соль, Сахар |
| Приготовить начинку | Смешать → Ингредиент, Приправа, Масса |
| Консервация | Стерилизовать → Банки → Время; Закрыть → Текст |

## Не добавлять как самостоятельные модули

Названия блюд, «с каждой стороны», «в один слой», «по вкусу», точный размер нарезки, давление, степень готовности и редкие авторские детали. Для них уже существует ограниченный модуль «Текст».
