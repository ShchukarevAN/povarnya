# Документация «Поварня»

Откройте `сайт/index.html` в браузере. Это автономная справка: поиск выполняется локально, без сервера и сети.

Каждая публичная сущность описана по четырём пунктам: цель, вход, выход и пример применения. При добавлении или изменении публичной функции обновляйте и соответствующую статью сайта.
