# Версии проекта

Проект использует Git. Основная ветка — `main`.

```bash
git status
git log --oneline
```

Номера версий задаются в `pubspec.yaml`, а изменения фиксируются в `CHANGELOG.md`. Формат — `0.<основная версия>.<итерация кода>`; последняя цифра повышается при каждом изменении исходного кода. Каждая значимая версия должна сопровождаться Git-коммитом и записью в журнале изменений.
